# L9Zone

A web catalogue for games, software, operating systems, and mobile content. Browse by category, search titles and tags, and open a dedicated page for each listing.

Features include featured content, user accounts, profiles, and an admin area for managing entries and categories. The app is built with React, TypeScript, Vite, and Firebase Authentication and Firestore.

## Run locally

```bash
npm install
npm run dev
```

Firebase settings are read from `firebase-applet-config.json`. To use a separate Firebase project, update that configuration and review `firestore.rules`.
